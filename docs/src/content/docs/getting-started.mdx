cv4pve-botgram runs **outside the cluster** (on a management VM, a small server, a container) and talks
only to the Proxmox VE REST API on port 8006. Nothing is installed on the nodes. The machine it runs on
must reach the nodes and, on the Internet, Telegram: the bot connects out and waits for your messages,
so no port is opened towards your network.

## Before the first run

You need two things:

1. **A Telegram bot and its token**, created in a minute from the Telegram app: see
   [Telegram bot](/cv4pve-botgram/telegram-bot/).
2. **A Proxmox VE user and API token** with the privileges for what the bot should do: see
   [Permissions](/cv4pve-botgram/permissions/).

## First run

```bash
cv4pve-botgram --host=pve1.local --api-token='bot@pve!bot=<uuid>' --token='<telegram-bot-token>' --chatsId=<chat-id>
```

The bot logs in to the cluster and to Telegram, then prints who it is:

```text
Start listening
Telegram
  Bot User: @your_pve_bot
  Bot UserId: @123456789
Proxmox VE
  pve1.local:8006
Press Ctrl+C to stop.
```

It stays in the foreground until it is stopped. Open the chat with your bot in Telegram and send `/help`: the bot answers with the list of its commands,
described in [Commands](/cv4pve-botgram/commands/).

## Options

| Option | What it does |
|---|---|
| `--token` | Token of the Telegram bot, from BotFather. Required. |
| `--chatsId` | Telegram chat IDs allowed to use the bot, separated by commas. See [Restrict the bot to your chats](/cv4pve-botgram/telegram-bot/#restrict-the-bot-to-your-chats). |

The bot runs until it is stopped: Ctrl+C in a terminal, `systemctl stop`, or the Windows service manager.
To keep it running after you close the terminal, see [Run as a service](/cv4pve-botgram/service/).

Host, API token, username and password, certificates and keeping the options in a file: see
[Connection](/cv4pve-botgram/connection/).

:::danger[Always set --chatsId]
Without `--chatsId` the bot answers **every** chat: anyone who finds the bot in Telegram can use it with
the privileges of its API token. Set it on every run that is not a first test.
:::
