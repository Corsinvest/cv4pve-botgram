cv4pve-botgram talks to the Proxmox VE REST API of any node of the cluster. Create the user and API token
first: see [Permissions](/cv4pve-botgram/permissions/).

## Options

<CliConnection user="bot@pve" />

## Options in a file

The bot runs with the same options every time, and two of them are secrets: keep them in a file readable
only by the account that runs the bot, not on the command line of a service.

<CliResponseFiles
  tool="cv4pve-botgram"
  user="bot@pve"
  token="bot"
  extra={['# Telegram bot, see Telegram bot', '--token=<telegram-bot-token>', '--chatsId=123456789,987654321']}
  run="--service-mode"
/>
