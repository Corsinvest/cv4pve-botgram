## Why

A VM hangs at night, or a node needs a reboot while you are away from your desk. The Proxmox VE web
interface is behind the company network: reaching it means a VPN and a laptop.

cv4pve-botgram puts the actions you need in those moments in a Telegram chat. The bot runs inside your
network, next to the cluster, and you talk to it from the phone you already carry. It connects out to
Telegram and waits for your messages: no port has to be opened towards your network.

## Outside the nodes, API only

cv4pve-botgram runs outside the cluster (on a management VM, a small server, a container) and talks
only to the Proxmox VE REST API. Nothing is installed on the nodes and no SSH or root shell is needed: an
API token with the privileges listed in [Permissions](/cv4pve-botgram/permissions/) is enough. Give it
more than one node and it connects to the first one that answers, so it still works while a node is down.

What a chat can do is exactly what the token is allowed to do: a token that can only start and stop
guests makes a bot that can only start and stop guests.

Prefer a web interface? [cv4pve-admin](https://github.com/Corsinvest/cv4pve-admin) runs the same bot as
its [Bots](https://corsinvest.github.io/cv4pve-admin/modules/bots/) module, configured from the browser.
